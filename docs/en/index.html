Features

Notifications pass through. Only what gets distilled stays.

📥Notification capture

Reads notifications after you grant access. Nothing leaves the device until you trigger a summary.

🧹Ad filtering

An on-device value threshold drops ads, marketing and low-signal notifications before they ever cost an AI call.

✨AI summarization

Pick your own model (via OpenRouter) to summarize and extract key points from selected notifications.

📌Important records

Extracts key items from notifications into records you can trace back, edit, and delete.

🌅Daily briefing

A home-screen widget and a morning notification recap of yesterday's key points.

📅Calendar integration

Events found in notifications are turned into calendar entries automatically.

🔔Notification history

Every notification is reviewable and searchable, filterable by app and keyword.

⏱️Background processing

Optional JobService summaries on a schedule, with no manual trigger required.

🔒On-device encryption

Keys and sessions are encrypted through Android Keystore. Your data stays on your phone.

Install

Three steps, about two minutes total.

Download and install the APK

Tap "Download APK" above. On first install from a browser, allow the source when prompted; Play Protect may scan and warn, which is expected.

Grant notification access

Open MindAI and follow the prompt to enable notification access. Only notifications within the scope you authorize are read.

Add your OpenRouter API key

Enter your key in Settings, pick a model, and you're summarizing. The key is stored locally and used only for your own AI requests.

About install warnings: Since Android 8.0, "unknown sources" is granted per app — just allow it when prompted. The package is signed with v2/v3 and you can verify it against the checksums below. Google Play listing is in preparation.

FAQ

The four questions people ask most.

Is MindAI safe? Does my notification content leave my phone?

Notification content does not leave your device unless you explicitly trigger a summary. Keys and sessions are stored encrypted via Android Keystore; AI summaries require your own OpenRouter API key, so requests go only to the account behind that key — no third-party relay server is involved.

Is MindAI paid? Do I need an API key?

The app itself is free and open source (MIT). AI summarization requires your own OpenRouter API key, billed by OpenRouter. On-device ad filtering, notification history, and the daily briefing need no key and cost nothing.

Which Android versions are supported?

Android 8.0 (API 26) and above, covering the vast majority of Android devices in use today.

Is MindAI open source?

Yes. The source is hosted on GitHub under the MIT license — build it yourself, audit it, or fork it.
