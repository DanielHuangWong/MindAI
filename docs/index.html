把通知变成记忆

MindAI 读取你授权的通知，本地过滤广告噪音，AI 提炼真正重要的事，自动沉淀为可追溯的记录。原始数据端侧加密，不出你的手机。

功能

通知只是过客，被提炼出来的才留下来。

📥通知采集

授权通知监听后读取通知，未经你触发总结，内容不出设备。

🧹广告过滤

本地价值门槛先行剔除广告、营销和低信号通知，不浪费一次 AI 调用。

✨AI 总结

自选模型（OpenRouter），对选定通知做摘要和要点提炼。

📌重要记录

从通知中提取关键事项，生成可追溯、可编辑、可删除的记录。

🌅每日简报

桌面小组件与通知晨间速览昨日重点。

📅日历集成

通知中的日程自动创建日历事件。

🔔通知历史

全部通知可回看、可搜索，按 App 和关键词筛选。

⏱️自动处理

可选 JobService 定时后台总结，无需手动触发。

🔒端侧加密

密钥与会话经 Android Keystore 加密，隐私不出手机。

界面

深色模式，核心操作都在一屏之内。

安装

三步开始，全程约两分钟。

下载并安装 APK

点击上方「下载 APK」。首次从浏览器安装时，按系统提示允许该来源；Play Protect 可能扫描并提示，属正常现象。

授予通知监听权限

打开 MindAI → 按引导开启「通知使用权」。仅采集你授权范围内的通知。

配置 OpenRouter API Key

设置中填入 Key，选择模型，即可开始总结。Key 仅存本地，只用于你的 AI 请求。

关于安装提示：Android 从 8.0 起对「未知来源应用」逐应用授权，按提示允许即可。安装包经过 v2/v3 签名，可用下方校验值核对完整性。Google Play 上架准备中。
